# ex07

Moving https://jacksoncareer.me from Railway to AWS (EC2 for the app, Single-AZ RDS PostgreSQL for the database). The architecture diagram is in the README: [Architecture](../../README.md#architecture). The full record is in [`aws-migration.md`](aws-migration.md) and [`migration-notes.md`](../../migration-notes.md).

## 1. Architecture decision

 I chose EC2 with a managed RDS PostgreSQL database over EC2 with PostgreSQL on the same server and over Lambda with API Gateway and RDS. This was the highest monthly cost of the three (about $28/month) in exchange for learning to run a server myself without having to manage backups and patching for the database.

## 4. Cutover status

`jacksoncareer.me` moved to AWS on **2026-11-09, about 23:06 UTC**. In Cloudflare, the root `CNAME` to Railway was replaced with an `A` record to the Elastic IP, DNS only. A comparison of the zone before and after showed every other record (Zoho MX, SPF, DKIM, DMARC, `www`) unchanged. After the switch, email in both directions and GA4 Realtime still worked.

## 5. Cost

**Estimate from section 6 (from the record):** about **$28.28/month**, from AWS's public us-east-1 prices read on 2026-11-03, before credits:

| Item | $/month |
|---|---|
| EC2 `t3.micro` | 7.59 |
| RDS `db.t3.micro`, Single-AZ | 13.14 |
| RDS storage, 20 GB gp3 | 2.30 |
| EC2 disk, 20 GB gp3 | 1.60 |
| Public IPv4 (Elastic IP) | 3.65 |
| Backups and data transfer | about 0 |
| **Total** | **28.28** |

`db.t3` always runs in Unlimited mode, so sustained database CPU above its baseline would cost extra. My login can't read billing, so the actual figure comes from the account owner's billing page.
